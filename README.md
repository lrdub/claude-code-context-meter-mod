# context-meter

Claude Code mod: a horizontal bar showing context usage against a 150k-token budget (can exceed 100%). In the terminal it sits on the status line; in the desktop app, which does not draw mod status lines, it is a band above the prompt.

## Install

At a Claude Code terminal prompt:

```
/plugin install context-meter --marketplace lrdub/claude-code-context-meter-mod
```

Answer `y` to add the marketplace, then pick the user scope.
